# 오늘의 메뉴 추천 웹페이지

웹페이지 소개
-------------
이 프로젝트는 사용자가 **날씨, 기분, 음식 종류, 예산**을 선택하면 조건에 맞는 메뉴를 카드 형태로 추천하는 웹 애플리케이션입니다.

주요 기능
---------
- 예산 필터는 **정확히 일치하는 음식**만 후보로 사용합니다.
- 음식 종류가 `상관없음`이 아닌 경우, 그 종류에 정확히 일치하는 음식이 우선 후보가 됩니다.
- 날씨 일치 시 2점, 기분 일치 시 1점을 부여하여 가장 높은 점수를 받은 음식 중 하나를 추천합니다.
- `재추천` 버튼은 가능한 경우 직전에 추천된 메뉴를 제외합니다.
- 선택한 예산에 맞는 메뉴가 없으면 다른 예산 메뉴를 추천하지 않고 안내 메시지를 표시합니다.

파일 구조
---------
- `index.html`: 사용자 인터페이스 구조 및 폼
- `style.css`: 반응형 화면 스타일과 버튼/카드 디자인
- `app.js`: 추천 알고리즘, 화면 전환, 이미지 로딩 처리
- `images/`: 각 메뉴 이미지 파일을 저장하는 폴더

추천 알고리즘 동작 순서
---------------------
1. 사용자가 폼을 제출하면 `form.submit` 이벤트로 `event.preventDefault()` 처리 후 조건을 읽습니다.
2. 선택한 **예산**과 정확히 일치하는 메뉴만 후보로 필터링합니다.
3. 선택한 **음식 종류**가 `상관없음`이 아니면 같은 종류만 추가로 우선 필터링합니다.
4. 필터링된 후보에 대해 날씨와 기분 점수를 계산합니다.
   - 날씨 일치: 2점
   - 기분 일치: 1점
5. 점수가 가장 높은 메뉴들 중에서 무작위로 하나를 추천합니다.
6. `재추천`은 이전 추천을 가능한 한 제외하여 새로운 메뉴를 보여줍니다.
7. 예산 후보가 없으면 `선택한 예산에 맞는 메뉴가 없습니다.` 메시지를 표시합니다.

실행 방법
---------
1. 프로젝트 루트에서 `index.html`을 브라우저로 엽니다.
2. 원하는 선택지를 고르고 `추천 받기` 버튼을 클릭합니다.
3. `재추천` 또는 `홈` 버튼으로 결과를 다시 확인하거나 첫 화면으로 이동합니다.

GitHub Pages 배포 시 상대경로 주의사항
--------------------------------
- 이미지와 CSS, JavaScript는 모두 **상대경로**(`./images/...`, `style.css`, `app.js`)로 연결되어 있습니다.
- GitHub Pages에 배포할 때도 파일 구조가 그대로 유지되어야 합니다.

추가 설명
---------
- 예산 조건은 **필수 조건**이며, 예산이 일치하지 않는 메뉴는 절대 후보가 되지 않습니다.
- 날씨와 기분은 **점수 조건**입니다. 예산이 일치한 메뉴 중에서 날씨와 기분 일치 여부로 추천 우선순위를 정합니다.
